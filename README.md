# ジャーナリングタイマー（朝焼け版）

[kayumori/j-timer](https://github.com/kayumori/j-timer) の配色違い。動作は同じで、朝焼けを基調に組み直したもの。
ライトとダークの両方を持ち、右端のスイッチで切り替えられる。

## 公開 URL

https://kayumori.github.io/j-timer-dark/

Notion のページで `/embed` → 上記 URL を貼り付けて使う。

## テーマ

右端の**スイッチ**でライト / ダークを切り替える。選んだテーマはそのブラウザに保存され、次に開いたときも維持される。

- **ダーク**（既定）— 夜明け前の空
- **ライト** — 日が差した朝の色

最初からライトで開きたい場合は末尾に `?theme=light` を付ける。
テーマの決定順は「スイッチで選んだ設定 → `?theme=` → ダーク」。一度スイッチを操作すると、以降はそちらが優先される。

## 仕様

- 分数を指定してスタート。残り時間をリングの進捗で表示する
- 進捗に応じてフェーズのメッセージが 4 段階で切り替わる
- 空は進行に合わせて「夜明け前 → 朝焼け → 陽が昇る」へ変化する。**枠の中だけ**で描くので、枠外は Notion のページ色（`#fff` / `#191919`）のまま
- 枠は内壁のグラデーション（`--rim`）と縁の 1 本線（`--inset`）の 2 層で、窪んだ盤面に見せている
  - ライトは上から光が入る想定で、上辺の内壁がいちばん濃く落ちる
  - ダークは黒い影ではなく**白い光**を内側に入れている。暗い面では影より光のほうが縁が立つため
- リングの弧は、始まり側の赤みから朝日のオレンジへ流れる
- 計測中にテーマを切り替えても、カウントは止まらずその時点の色で塗り直される
- 完了時にチャイム（Web Audio API で生成。音源ファイルは持たない）
- 外部リソースなし。`index.html` 単体で動作する

## 元の版との違い

| | 元（j-timer） | この版 |
| --- | --- | --- |
| 基調 | スレート＋インディゴ | 朝焼けのオレンジ |
| テーマ | ライトのみ | ライト / ダーク（スイッチ切替） |
| アクセント | `#6366f1` | `#f97316`（ライト）/ `#ff9a4d`（ダーク） |
| リング | 単色 | 赤み → オレンジのグラデーション |
| 進行中の背景 | 青 → 琥珀 → 緑 | 夜明け前 → 朝焼け → 陽光 |

## 色の変え方

配色は `index.html` 冒頭の `:root`（ライト）と `html[data-theme="dark"]`（ダーク）に CSS 変数としてまとめてある。
JS 側も毎回そこから読み直しているので、色を変えるときはこの 2 か所だけ触ればよい。
進行中の空の色だけは、4 段階の配列として JS の `SKY` に持たせている。
