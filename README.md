# ジャーナリングタイマー（ダークモード版）

[kayumori/j-timer](https://github.com/kayumori/j-timer) のダーク配色版。動作は同じで、配色だけ暗い面用に組み直したもの。

## 公開 URL

https://kayumori.github.io/j-timer-dark/

Notion のページで `/embed` → 上記 URL を貼り付けて使う。ダークモードのページ向け。
ライトのページには元の [j-timer](https://kayumori.github.io/j-timer/) を使う。

## 仕様

- 分数を指定してスタート。残り時間をリングの進捗で表示する
- 進捗に応じてフェーズのメッセージが 4 段階で切り替わる
- 背景は進行に合わせて「夜の青 → 琥珀 → 深い緑」へゆっくり変化する
- 完了時にチャイム（Web Audio API で生成。音源ファイルは持たない）
- 外部リソースなし。`index.html` 単体で動作する

## 元の版との違い

| | ライト（j-timer） | ダーク（この版） |
| --- | --- | --- |
| 地色 | `#f8fafc` | `#121316` |
| カード | `#ffffff` | `#1a1b1f` |
| リング軌道 | `#e2e8f0` | `#2b2d34` |
| アクセント | `#6366f1` | `#818cf8` |
| スタートボタン | 暗い面に明るい文字 | 明るい面に暗い文字（反転） |
| 進行中の背景 | パステルの青 → 琥珀 → 緑 | 明度を落としたまま色相だけ動かす |

アクセントを一段明るくしているのは、`#6366f1` のままだと暗い地色に沈んでリングの進捗が読み取りにくいため。

## 色の変え方

配色はすべて `index.html` 冒頭の `:root` に CSS 変数としてまとめてあり、JS 側もそこから読んでいる。
色を変えるときは `:root` だけ触ればよい（進行中の背景グラデーションのみ `jtBg()` 内に直接記述）。
