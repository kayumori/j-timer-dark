# ジャーナリングタイマー（夜明け版）

[kayumori/j-timer](https://github.com/kayumori/j-timer) の配色違い。動作は同じで、夜が明けていく流れを基調に組み直したもの。
ライトとダークの両方を持ち、右端のスイッチで切り替えられる。

## 公開 URL

https://kayumori.github.io/j-timer-dark/

Notion のページで `/embed` → 上記 URL を貼り付けて使う。

## テーマ

右端の**スイッチ**でライト / ダークを切り替える。選んだテーマはそのブラウザに保存され、次に開いたときも維持される。

最初からライトで開きたい場合は末尾に `?theme=light` を付ける。
テーマの決定順は「スイッチで選んだ設定 → `?theme=` → ダーク」。一度スイッチを操作すると、以降はそちらが優先される。

**どちらのテーマも待機中は暗い。** 時間の経過とともに明けていく作りなので、ライトを選んでも最初は夜の色から始まる。

## 空の変化

進行に合わせて、下から光が上がる放射グラデーションで 4 段階を渡っていく。**枠の中だけ**で描くので、枠外は Notion のページ色（`#fff` / `#191919`）のまま。

| 段階 | ダーク | ライト |
| --- | --- | --- |
| 待機 | 夜の青 | 黒っぽい青 |
| 序盤 | 地平線が色づく | 地平線がオレンジ |
| 中盤 | 朝焼け | 朝焼け |
| 完了 | 白い朝 | 明るい青空 |

## 仕様

- 分数を指定してスタート。残り時間をリングの進捗で表示する
- 進捗に応じてフェーズのメッセージが 4 段階で切り替わる
- リングの弧は、夜は淡い日輪、朝は空に負けないよう濃いオレンジへ変化する
- 枠は内壁のグラデーション（`--rim`）と縁の影（`--inset`）の 2 層で、窪んだ盤面に見せている。夜は白い光、朝は黒い影で、進行に合わせてクロスフェードする
- 計測中にテーマを切り替えても、カウントは止まらずその時点の色で塗り直される
- 完了時にチャイム（Web Audio API で生成。音源ファイルは持たない）
- 外部リソースなし。`index.html` 単体で動作する

### 文字の反転について

どちらのテーマも待機中は暗く、完了時は明るい。そのままだと終盤に文字が背景へ埋もれるため、**進捗 66%（`FLIP`）の地点で文字・ボタン・枠線を一気に反転**させている。

少しずつ混ぜる方式は採らない。中間で背景と同じ明るさのグレーを通ってしまい、最も読みにくい状態が長く続くため。切り替えは一瞬で行い、見た目だけ CSS の transition で 0.8 秒かけて渡している。

着地の色はテーマで変えていて、白い朝に着地するダークは暖色の黒（`#2b1a10`）、青空に着地するライトは青寄りの黒（`#16243a`）。青空の上に暖色の文字を置くと濁るため。

## 元の版との違い

| | 元（j-timer） | この版 |
| --- | --- | --- |
| テーマ | ライトのみ | ライト / ダーク（スイッチ切替） |
| 進行中の背景 | 青 → 琥珀 → 緑（枠の外） | 夜 → 朝焼け → 朝（枠の中） |
| グラデーション | 斜めの直線 | 下から上がる放射 |
| リング | 単色 `#6366f1` | 進行に合わせて色が変わる |
| 文字色 | 固定 | 進捗 66% で反転 |

## 色の変え方

- 待機中（＝夜）の値は `index.html` 冒頭の `:root`（ライト）と `html[data-theme="dark"]`（ダーク）に CSS 変数として置いてある。これは JS が動く前の初期値
- 進行中の実際の色は JS が毎フレーム上書きする。空は `SKY`、UI の夜 → 朝の対応は `UI` にまとめてある
- 反転のタイミングは `FLIP` の値
